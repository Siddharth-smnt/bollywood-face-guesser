# Display thumbnails

Run `prepare_gallery.py` as described in the main README. It creates
`gallery/data/<celebrity folder>/<original image filename>.jpg` for every
readable image referenced by the supplied `filenames.pkl`.

The original full-size dataset was not uploaded, so no actual celebrity
thumbnails are included yet. Do not place unrelated images here as if they
were the original matches. The application shows a message when a matched
thumbnail is missing.
